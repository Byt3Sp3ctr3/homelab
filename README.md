# homelab
Mes scripts et déploiements perso. Rien de bien sérieux, surtout des notes pour moi-même.

- `services/` : un dossier par service auto-hébergé (docker compose), copier `.env.example` en `.env`
  - `forum/`, `monitoring/`, `proxy/`
- `tools/` : petits outils (nettoyage CSV, sauvegardes)
- `docs/` : notes en vrac

`ping_check` est remplacé par uptime-kuma.
